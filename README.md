# Тренажёр iOS-интервью

**Открыть: https://blashkin.github.io/ios-trainer/**

Карточки для подготовки к техническим собеседованиям: читаешь вопрос, отвечаешь вслух как интервьюеру, сверяешься с эталоном и отмечаешь "знал / плавал / не знал".

100+ карточек по темам: Swift, многопоточность, архитектура, UIKit/SwiftUI, networking, базы данных, тестирование, алгоритмы, profiling, live coding ("что выведется?") и KMP для нативщиков.

Что умеет:

- фильтры по темам; "База" - must-have фундамент, "Слабые" - твой персональный второй круг
- полнотекстовый поиск по карточкам
- прогресс сохраняется в браузере (localStorage)
- клавиатура: space - показать ответ, 1/2/3 - оценка, стрелки - навигация

Технически это один самодостаточный index.html - без сборки, фреймворков и зависимостей.
